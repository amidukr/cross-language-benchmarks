# Task 2.3. Analyze enum dispatch assembly

Inspect the generated code for [Task 2.1](2.1-implement-enum-dispatch.md)
across the [benchmark targets](../agent-rules/targets.md). Follow the repository
[project structure](../agent-rules/project-structure.md) and
[assembly analysis rules](../agent-rules/assembly-analysis.md).

## Work to perform

- Use a representative Task 2.1 case. Match the recorded workload settings
  and build configuration when a timing run is available. Reuse existing
  artifacts or collect evidence in a separate diagnostic run. Use only clean
  performance-run timings for comparisons with Task 2.2.
- Locate the hot loop in `run` or the optimized caller that contains it.
  For each target, determine how the enum or integer tag decision is
  implemented. Look for conditional branches, branchless selection, jump
  tables, unrolling, vectorization, or duplicated specialized paths. Confirm
  whether virtual, interface, function-pointer, delegate, or closure dispatch
  is absent from the timed loop.
- Inspect how the code loads the tag and operand, selects addition or
  multiplication, and accumulates the wrapping 32-bit checksum. For JIT
  targets, compare early and optimized versions when both are available. For
  CPython, identify the tag access, control flow, and arithmetic in bytecode.
- Attempt collection for each applicable target. Continue when a toolchain,
  decoder, or usable artifact is unavailable. Identify skipped targets and
  capture failures with their reasons.

## Outputs

- Include a target comparison table with the evidence type, observed
  tag-dispatch mechanism, tier or build configuration, and capture status.
  Link to the raw files and include short annotated excerpts for the findings
  that matter.

## Done when

Every target is accounted for in the report. Each tag-dispatch conclusion
points to a specific listing or bytecode excerpt. If relating code generation
to Task 2.2 timings or comparing it with Task 1.3, identify the matching
configurations and distinguish observations from explanations that would
require a controlled comparison.
